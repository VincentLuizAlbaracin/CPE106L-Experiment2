# CPE106L Experiment 2

File Handling, Exception Handling, and Modular Programming in Python.

## Contents

| Folder | Description |
| --- | --- |
| `exp2/activity1_file_handling` | text, CSV and JSON file programs |
| `exp2/activity2_exception_handling` | input, file and calculator error handling |
| `exp2/activity3_modules` | `Utilities.py` module and a program that imports it |
| `exp2/postlab_student_management` | Student Management System (student, file_manager, utilities, main) |

## How to run

Open a terminal in the program's folder and run `python <file>.py`.
For the PostLab system, run `python main.py` inside `exp2/postlab_student_management`.
